# ⚡ EV Charging Stations Management & Prediction System

🔗 **Live Demo:** https://ev-charging-stations-management.onrender.com

A full-stack EV charging station management platform that helps users explore charging stations and estimate charging costs.

## Features
- EV charging station management
- Charging cost calculator
- Station listing and comparison
- Load prediction functionality
- Interactive and responsive web interface

## Tech Stack
- Java
- Spring Boot
- HTML, CSS, JavaScript
- Spring Data JPA / Hibernate
- MySQL
- Render (Deployment)
